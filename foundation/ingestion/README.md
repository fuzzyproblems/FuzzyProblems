# Local source retrieval

Use [PDF intake](../guidance/PDF_INTAKE.md) for registration. Originals stay in `Objectives/`, `Textbooks/`, `PastPapers/`. Content hashes identify sources, exact relative aliases identify locations and one-based original PDF page numbers anchor evidence. Verified printed pagination is separate. The current catalogue is `foundation/intake/catalog.json`; each source’s `intake_cache` points to raw extraction, cleaned/classified text, OCR and SQLite FTS under `foundation/intake-cache/`.

`search QUERY --limit 8` searches textbook teaching candidates. Bounds are 1–30 results. Use `--source SOURCE_ID` for one source; role-separated objectives/pastpapers searches are discovery only. `--recovery` includes navigation and other non-teaching pages. Snippets do not establish support; read bounded original `page SOURCE_ID NUMBER --context 1` continuations. Use `render` for original visual inspection, into `work/` or the current pack, and `ocr` for a sparse original page. Never load whole textbooks into model context.

Raw native text, geometry, extraction flags, removed running matter and classifications are preserved separately from cleaned search. OCR is local Tesseract with no model call and retains engine/language/settings/source/page bindings, text and unreviewed word boxes. Sparse extraction and empty OCR remain explicit discovery limits. Do not infer a blank original or approve highlights from OCR boxes alone.

Only supplied textbook pages establish facts. Interpret original qualifications, captions, page continuations, units, symbols and context. Original-page inspection is needed to verify identity, extraction quality, source figures and ambiguous text. Exact matching uses conservative normalization without changing scientific meaning. Retrieval is not a permanent relevance whitelist; reviewer searches may cover all supplied textbooks.

`source-check` validates originals/aliases, cache receipts, raw page identity, cleaned/index equivalence, FTS integrity and OCR status. `rebuild-cache --check` validates derived indexes. `--rebuild` reconstructs indexes from intact preserved payloads, without PDF extraction, OCR, educational editing or approval. A damaged original/raw/cleaned/OCR payload must be reconciled explicitly; rebuilding an index cannot legitimize it. Unavailable originals make evidence unusable. Re-run intake after additions/replacements and reassess affected records.
