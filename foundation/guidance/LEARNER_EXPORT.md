# Build and deliver

After independent educational acceptance, run `build PACK`, `check PACK`, then `publish PACK --folder VERSION`. Use a new portable output name; never replace an existing export. The exact learner allowlist is the index, each declared chapter, practice, answers, Anki HTML/TSV/note-type utility and both evidence PDFs. Research, coverage, handoffs, receipts, logs and operational records remain internal.

Render educational fields only. Teach directly with the complete original objective, context, supported mechanisms, distinctions and qualifications. Do not include narration about research, authorship, review, production, approval, counts, packaging or model settings. Preserve real scholarly attribution and readable book/edition/original-PDF-page citations.

Every citation occurrence has a corresponding repeated original page in each evidence PDF, in guide order, then answers, then cards. Internal caching may reuse geometry but cannot deduplicate occurrences. Match native passages exactly or use independently reviewed coordinates; preserve legitimate original page content. An ambiguous highlight may remain unmarked with a recorded limitation, but absent quotation, wrong source/page or missing support blocks acceptance. Do not rasterize evidence pages or use model OCR.

HTML uses inline styling, embedded source figures and relative local links. Normal QA compares exported teaching, table cells, questions/answers, citation mappings, figures, Anki fields and exact output bytes. No routine screenshots, print/mobile gate, separate presentation receipt or privacy scan is required. Use one to three targeted desktop diagnostics for a substantive presentation defect or changed layout; cosmetic differences do not block. Original educational figure inspection is separate.

Published guides live directly beneath `output/` by default. Separate objectives of one lesson may share a collection: pass the same `--folder Example-Lesson/Objective-1-v1` to `python pipeline.py build PACK` and `python pipeline.py publish PACK`. The build records the full destination internally and calculates textbook URLs from its checked depth; publication rejects a mismatch, including at the same depth. Later builds retain that binding unless `--folder` changes it. Choose a new output version and preserve previous exports.

Root `StudyGuide.html` is regenerated after publication. Each nonempty grouping folder gets `navigation.html` linking its immediate guides and groups, plus parent/main links. The catalogue supports arbitrary depth and mixed guide/group folders. A valid sole `Objective N · topic` chapter opens directly, including earlier versions; multi-chapter, unsafe or nonconforming guides open their index. After folder changes run `python regenerate_study_guide.py` or `python pipeline.py catalogue`. When moving study files to another depth, create a new checked export with corrected original-source URLs; catalogue regeneration alone cannot repair links inside moved guides or change their bytes.

Anki utilities describe `StableID`, `Front`, `Back`, `Sources`, `Tags` and the tag-field mapping. Continuing cards retain IDs; new cards get new IDs. Preserve task mappings and user-approved/delegated label hierarchy. TSV is UTF-8 with deliberate HTML escaping and no accidental delimiters. Validate round-trip fields and duplicates; do not claim native Anki import unless actually performed.

Browser Print can print the HTML or save it as PDF using the supplied print styles. Evidence PDFs are separate original-page source companions. `archive PACK --name VERSION.zip` packages the exact learner allowlist with neutral metadata; original textbook hyperlinks require the matching project-relative inputs, while evidence PDFs travel with the pack. Share supplied textbook material only with appropriate rights.

An archive contains the leaf delivery folder, not its enclosing collection folders. Restore that leaf at the originally checked relative destination and retain the matching `Textbooks/` tree. For the example above, restore `Objective-1-v1` under `output/Example-Lesson/`. Diagnostics, delivery configuration, working records and review receipts remain outside learner payloads. Share only the intended allowlisted files; manually copying the entire output tree also copies its separate diagnostic log.
