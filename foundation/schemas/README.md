# Structural contracts

The JSON schemas describe knowledge entries, authored pack content, evidence and coverage. Consult [FORMAT](../library/FORMAT.md) for field meanings and independent receipt requirements. The normal CLI also enforces `contracts.py`, source integrity, exact dependencies, citation matching and exported-content checks. Schema validity cannot establish factual support, complete coverage, explanatory depth or educational quality. No schema package is required at runtime.

Scopes, intake identities and handoffs are created by the operational commands. They remain unreviewed until actual independent judgments are recorded. Never fill pass fields from schema defaults. Use the current scoped dependencies and declared practice types, and preserve all record IDs and original wording.
